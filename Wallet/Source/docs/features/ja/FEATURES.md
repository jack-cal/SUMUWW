# SUMUWW Wallet Android 1.1.14

通常は外向きの接続を10件開き、主にブロックと取引の中継に使います。検証済みの予備接続をブロックの中継に使うことも、別のノードを探すために一時的に11件目を開くこともあります。合計の上限は125件です。外部からの接続は最大117件、外向きが10件なら最大115件です。 Android でウォレットを開く際のエラーを修正しました。端末のネットワーク接続の変化も検出できます。

1 SMW = 100,000,000 yugeon です。自動手数料はローカルの観測値に基づく3段階で、承認時間を保証するものではありません。yugeon/vB で手動入力もできます。送信前に、最終手数料と合計を SMW で確認してください。拒否された取引で残高が減ることはありません。

1 SMWの入力を1つ使う場合でも、お釣りの有無で手数料は変わります。入出力がすべてP2WPKHで手数料率が1 yugeon/vBの場合、0.99999890 SMWを送ると、お釣りはなく、手数料は110 yugeonです。同じ入力から0.8 SMWを送ると、お釣り用の出力が加わり、手数料は141 yugeonになります。手数料を差し引いた残額が、お釣りを後で使う費用も考慮した最低額に達すると、ウォレットはお釣りを返します。それ未満の残額は、送金を確定する前に表示される手数料に含まれます。ネイティブSegWit（P2WPKH）のウォレット入力では、ハッシュタイプを含む署名のサイズを最大71バイトとして見積もります。

`1 yugeon = 0.00000001 SMW`

`1 SMW = 100,000,000 yugeon`

自動手数料には現在の待機データ量、ブロック容量、取引の優先順位を反映します。過去のブロックの手数料は使いません。待機量が少ないときは最低料率を維持します。プレビューは更新され、最終確認時に手数料が固定されます。観測対象は接続中のローカルノードであり、全ノードではありません。

再起動後も、このノードで記録した取引の置換履歴が残ります。削除された取引は残高に反映されません。

採掘履歴では、各ブロックの新規発行報酬、取引手数料報酬、合計を分けて表示します。自分のウォレットが受け取った額は別に表示します。報酬の一部しか請求されていない場合、内訳を推定しません。ノードは手数料推定を含む28個のRPCメソッドを提供し、署名済み取引を検証・中継します。

## 送金手数料、確認済み取引と互換性

手数料は入力金額の合計から出力金額の合計を引いた値です。ウォレットが実際に有効なお釣りを作る場合だけ、見積もりにお釣り出力のサイズを含めます。ウォレットの基準に満たない残額は手数料に加えられ、最終手数料と総引落額が確認画面に表示されます。料率の単位は yugeon/vB です。仮想サイズは取引のウェイトを4で割り、切り上げた値です。

ウォレットは入力と出力を一度だけ選び、その同じ取引プランに署名します。確認後は保存済みの署名付き取引を送信し、取引の再構成や手数料の再計算は行いません。見積もりが期限切れになった場合や入力が先に使用された場合は、再確認が必要です。ローカルの待機キューへの受理は、ブロックでの承認とは異なります。

通常の P2WPKH 送金では low-R・low-S 署名を生成し、SIGHASH_ALL バイトを含めて最大71バイトとします。これはウォレットの署名・サイズ見積もりの方針であり、ほかの有効な署名に新たなコンセンサス制限を設けるものではありません。署名が短ければ実際の仮想サイズは見積もりより小さくなることがあります。推奨料率は引き続き自ノードの待機キューに基づきます。

## Android の署名互換性

ウォレットファイルの形式、アドレス、既存のコインは変更していません。従来の暗号化バックアップを新アプリで復元し、同じウォレットを引き続き使えます。 Android ノード 0.6.103 とウォレット 1.1.14 は、新しく生成したリリース署名鍵を使います。別の鍵で署名された既存アプリには上書きインストールできません。暗号化したウォレットのバックアップと動作する復元方法を確保するまで、旧アプリとそのデータを保管してください。更新を無理にインストールするために、先に旧アプリを削除しないでください。
