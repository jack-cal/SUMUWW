Αν η εκτίμηση έχει λήξει ή μια είσοδος έχει ήδη δαπανηθεί, απαιτείται νέος έλεγχος. Η αποδοχή στην τοπική ουρά δεν ισοδυναμεί με επιβεβαίωση σε μπλοκ.
