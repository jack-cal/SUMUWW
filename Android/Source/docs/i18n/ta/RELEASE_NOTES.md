# SUMUWW Android 0.6.99 · பதிப்பு குறிப்புகள்

மீண்டும் தொடங்கும்போது, முனையம் தானே சரிபார்த்த கடைசித் தொகுதியிலிருந்து தொடர்ந்து புதிய தொகுதிகளைச் சரிபார்க்கிறது. சேமித்த சரிபார்ப்புப் பதிவு இல்லையெனில் அல்லது அதன் விவரங்கள் பொருந்தாவிட்டால், சேமித்த வரலாற்றை மீண்டும் சரிபார்க்கிறது.

SUMUWW Android 0.6.99 · முனை சங்கிலித் தரவைச் சரிபார்த்து, சேமித்து, பரப்பி, தேடலுக்கு வழங்குகிறது.
