# SUMUWW Android 0.6.99 · Рад чвора

После поновног покретања чвор наставља од последњег блока који је сам проверио и проверава нове блокове. Ако сачувани запис о провери недостаје или се подаци не поклапају, чвор поново проверава сачувану историју.

SUMUWW Android 0.6.99 · Чвор проверава, чува, прослеђује и даје на увид податке ланца.
