# SUMUWW Android 0.6.99 · Эксплуатация узла

После перезапуска узел продолжает с последнего блока, который он проверил локально, и проверяет новые блоки. Если сохранённая запись о проверке отсутствует или в ней есть расхождения, узел заново проверяет сохранённую историю.

SUMUWW Android 0.6.99 · Узел проверяет, хранит, передаёт и предоставляет данные цепочки.
