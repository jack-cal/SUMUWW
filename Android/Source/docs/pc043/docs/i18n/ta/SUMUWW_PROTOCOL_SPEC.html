கட்டணம், சரிபார்த்த பரிவர்த்தனை மற்றும் இணக்கத்தன்மை

உள்ளீடுகளின் மொத்தத்திலிருந்து வெளியீடுகளின் மொத்தத்தைக் கழித்தால் கட்டணம் கிடைக்கும். பணப்பை தனது வரம்பைப் பூர்த்தி செய்யும் மீதித்தொகையை உண்மையில் உருவாக்கும்போதுதான் அதன் வெளியீடு அளவு மதிப்பீட்டில் சேர்க்கப்படும். வரம்புக்குக் குறைவான மீதித்தொகை கட்டணத்தில் சேர்க்கப்படும்; இறுதிக் கட்டணமும் மொத்தப் பிடித்தமும் சரிபார்ப்பதற்குக் காட்டப்படும். கட்டண விகிதத்தின் அலகு yugeon/vB. பரிவர்த்தனை எடையை நான்கால் வகுத்து மேல்நோக்கி முழு எண்ணாக்கினால் மெய்நிகர் அளவு கிடைக்கும்.

பணப்பை உள்ளீடுகளையும் வெளியீடுகளையும் ஒருமுறை தேர்ந்தெடுத்து அதே பரிவர்த்தனைத் திட்டத்தில் கையொப்பமிடுகிறது. உறுதிசெய்யும்போது சேமித்த கையொப்பமிட்ட பரிவர்த்தனையே அனுப்பப்படும்; அது மீண்டும் அமைக்கப்படாது, கட்டணமும் மறுகணக்கிடப்படாது. மதிப்பீட்டின் காலம் முடிந்தாலோ ஓர் உள்ளீடு ஏற்கெனவே செலவிடப்பட்டாலோ மீண்டும் சரிபார்க்க வேண்டும். உள்ளூர் வரிசையில் ஏற்கப்பட்டதையே தொகுதியில் உறுதியானதாகக் கருதக்கூடாது.
