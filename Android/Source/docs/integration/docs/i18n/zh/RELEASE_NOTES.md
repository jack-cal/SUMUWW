# SUMUWW Android 0.6.103 · 版本说明

使用一笔 1 SMW 的输入时，手续费取决于是否需要找零。假设输入和输出都是 P2WPKH，费率为 1 yugeon/vB，发送 0.99999890 SMW 无需找零，手续费为 110 yugeon。用同一笔输入发送 0.8 SMW 时，会多一个找零输出，手续费为 141 yugeon。扣除手续费后，只有剩余金额达到找零的最低金额，钱包才会找零。这个门槛考虑了以后花费这笔找零的成本。低于门槛的余额会计入发送确认页显示的手续费。估算原生隔离见证（P2WPKH）钱包输入的大小时，签名连同哈希类型最多按 71 字节计算。

重启后，节点从本地上次验证的区块继续，检查新区块。如果保存的验证记录缺失或不一致，节点会重新验证已保存的历史记录。

## 交易手续费、确认内容与兼容性

手续费等于输入金额总和减去输出金额总和。只有钱包实际创建符合要求的找零时，估算才计入找零输出。低于钱包找零门槛的余额会计入手续费，确认前会显示最终手续费和总扣款。费率单位为 yugeon/vB；虚拟大小等于交易权重除以四后向上取整。

钱包只选择一次输入和输出，并按同一交易方案生成签名。确认后提交的是已保存的签名交易，不会重新构造交易或重算手续费。报价过期或输入已被花费时，必须重新核对。进入本地待处理队列并不代表已获得区块确认。

普通 P2WPKH 转账使用 low-R、low-S 签名，连同 SIGHASH_ALL 字节在内最多为 71 字节。这是钱包的签名和大小估算策略，并不是对其他有效签名新增的共识限制。签名较短时，实际虚拟大小可能小于估算值。

## Android 签名兼容性

钱包文件格式、地址和已有币都没有改变。可在新应用中恢复原有的加密钱包备份，继续使用同一个钱包。 Android 节点 0.6.103 和钱包 1.1.14 使用新生成的发行签名密钥，无法覆盖安装到使用不同密钥签名的旧版本上。请先保留旧应用和数据，确认已取得钱包的加密备份及有效的恢复方式。不要仅为强行安装更新而卸载旧应用。
