เมื่อเริ่มทำงานอีกครั้ง โหนดจะทำงานต่อจากบล็อกล่าสุดที่ตรวจสอบไว้ในเครื่องและตรวจสอบบล็อกใหม่ หากไม่พบบันทึกการตรวจสอบที่เก็บไว้หรือข้อมูลไม่ตรงกัน โหนดจะตรวจสอบประวัติที่เก็บไว้อีกครั้ง

## เครือข่ายและที่อยู่

เครือข่ายสาธารณะคือ `sumuww` มีชื่อภายในว่า `dora` ตรวจสอบแฮชบล็อกกำเนิดด้านล่าง ที่อยู่มาตรฐานใช้ witness v0 P2WPKH และ HASH160 ของกุญแจสาธารณะ secp256k1 แบบบีบอัด ไม่บังคับ memo หรือ tag ปฏิเสธที่อยู่ผิดเครือข่ายและ checksum ผิด บันทึกแขนง HD รับเงิน/เงินทอนและดัชนี อย่าสมมติว่าใช้เส้นทางสร้างกุญแจแบบ Bitcoin

## ค้นหาธุรกรรมและบล็อก

`getrawtransaction` ค้นในสายโซ่ที่ใช้งานและ mempool ไม่ค้นธุรกรรมที่อยู่เฉพาะแขนงกำพร้า อินพุตระบุเอาต์พุตก่อนหน้า ไม่ใช่ที่อยู่ผู้ส่งเดียว `getblock` รับ `verbose` แบบ Boolean บล็อกที่เก็บแต่ไม่ใช้งานมี `active=false`, `confirmations=-1` ยังอ่านธุรกรรมดิบผ่านแฮชบล็อกได้ `findspendingtransaction` ค้นเฉพาะการใช้ที่ยืนยันในสายโซ่ปัจจุบัน null ไม่พิสูจน์ว่าใช้ได้ ตรวจ `gettxout` ด้วย `include_mempool=true` จำนวนยืนยันและสถานะใช้งานอาจเปลี่ยนเมื่อจัดสายโซ่ใหม่
