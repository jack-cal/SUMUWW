## 送金手数料、確認済み取引と互換性

手数料は入力金額の合計から出力金額の合計を引いた値です。ウォレットが実際に有効なお釣りを作る場合だけ、見積もりにお釣り出力のサイズを含めます。ウォレットの基準に満たない残額は手数料に加えられ、最終手数料と総引落額が確認画面に表示されます。料率の単位は yugeon/vB です。仮想サイズは取引のウェイトを4で割り、切り上げた値です。

ウォレットは入力と出力を一度だけ選び、その同じ取引プランに署名します。確認後は保存済みの署名付き取引を送信し、取引の再構成や手数料の再計算は行いません。見積もりが期限切れになった場合や入力が先に使用された場合は、再確認が必要です。ローカルの待機キューへの受理は、ブロックでの承認とは異なります。

通常の P2WPKH 送金では low-R・low-S 署名を生成し、SIGHASH_ALL バイトを含めて最大71バイトとします。これはウォレットの署名・サイズ見積もりの方針であり、ほかの有効な署名に新たなコンセンサス制限を設けるものではありません。署名が短ければ実際の仮想サイズは見積もりより小さくなることがあります。推奨料率は引き続き自ノードの待機キューに基づきます。Bitcoin と同様のサイズ計算を採用しても、Bitcoin ネットワークの料率を使うわけではありません。

## Android の署名互換性

ウォレットファイルの形式、アドレス、既存のコインは変更していません。従来の暗号化バックアップを新アプリで復元し、同じウォレットを引き続き使えます。 Android ノード 0.6.103 とウォレット 1.1.14 は、新しく生成したリリース署名鍵を使います。別の鍵で署名された既存アプリには上書きインストールできません。暗号化したウォレットのバックアップと動作する復元方法を確保するまで、旧アプリとそのデータを保管してください。更新を無理にインストールするために、先に旧アプリを削除しないでください。
