ホワイトペーパーの概要と現在の規則

SUMUWW · 2026-11-16 · 2.4

SUMUWWはUTXOを使う独立したSHA-256dチェーンです。1 SMWは100,000,000 yugeonです。採掘者は新規発行報酬と収録取引の手数料を受け取れます。手数料は既存コインの移転であり、最大発行量を増やしません。採掘履歴はブロック全体の報酬と自分の受取額を分けて表示します。自動手数料は現在のローカル待機列を使い、手動の単位はyugeon/vBです。目標間隔600秒は承認時間の保証ではありません。

手数料は、入力の合計からお釣りを含むすべての出力の合計を引いた額です。受取人には指定した金額がそのまま届きます。取引をブロックに含めたマイナーは手数料を受け取れます。

1 SMWの入力を1つ使う場合でも、お釣りの有無で手数料は変わります。入出力がすべてP2WPKHで手数料率が1 yugeon/vBの場合、0.99999890 SMWを送ると、お釣りはなく、手数料は110 yugeonです。同じ入力から0.8 SMWを送ると、お釣り用の出力が加わり、手数料は141 yugeonになります。手数料を差し引いた残額が、お釣りを後で使う費用も考慮した最低額に達すると、ウォレットはお釣りを返します。それ未満の残額は、送金を確定する前に表示される手数料に含まれます。ネイティブSegWit（P2WPKH）のウォレット入力では、ハッシュタイプを含む署名のサイズを最大71バイトとして見積もります。

元ブロック9,600から、活動応答とチェーンに登録された世代の3分の2を超える承認で候補一覧を証明します。従来のビーコンで証人3名を選び、事象の抽選確率は20%のままです。適用後、未完了の作業はA/Bの組と事象ビーコンを保ったまま選定回を更新できます。以前の応答は保存し、異なる回の応答を混ぜません。独立した運営者や全世界への到達性を証明するものではありません。準備記録・選定作業・完成証明は異なる件数です。11件から9件を引いて完成2件とは判断できません。

元ブロック9,600から稼働中の証人の選定証明が必須になります。以前の記録は保持されます。それまでにノードとウォレットを更新してください。旧版は累積作業量が同じ場合に異なるチェーンを選ぶ可能性があります。保留中の履歴も保持します。

送金手数料、確認済み取引と互換性

手数料は入力金額の合計から出力金額の合計を引いた値です。ウォレットが実際に有効なお釣りを作る場合だけ、見積もりにお釣り出力のサイズを含めます。ウォレットの基準に満たない残額は手数料に加えられ、最終手数料と総引落額が確認画面に表示されます。料率の単位は yugeon/vB です。仮想サイズは取引のウェイトを4で割り、切り上げた値です。

ウォレットは入力と出力を一度だけ選び、その同じ取引プランに署名します。確認後は保存済みの署名付き取引を送信し、取引の再構成や手数料の再計算は行いません。見積もりが期限切れになった場合や入力が先に使用された場合は、再確認が必要です。ローカルの待機キューへの受理は、ブロックでの承認とは異なります。

通常の P2WPKH 送金では low-R・low-S 署名を生成し、SIGHASH_ALL バイトを含めて最大71バイトとします。これはウォレットの署名・サイズ見積もりの方針であり、ほかの有効な署名に新たなコンセンサス制限を設けるものではありません。署名が短ければ実際の仮想サイズは見積もりより小さくなることがあります。推奨料率は引き続き自ノードの待機キューに基づきます。Bitcoin と同様のサイズ計算を採用しても、Bitcoin ネットワークの料率を使うわけではありません。
