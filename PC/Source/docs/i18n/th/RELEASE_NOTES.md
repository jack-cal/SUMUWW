# SUMUWW · บันทึกเวอร์ชัน

เมื่อใช้อินพุต 1 รายการมูลค่า 1 SMW ค่าธรรมเนียมจะขึ้นอยู่กับว่าต้องทอนเงินหรือไม่ หากอินพุตและเอาต์พุตทั้งหมดเป็น P2WPKH และอัตราค่าธรรมเนียมคือ 1 yugeon/vB การส่ง 0.99999890 SMW จะเสียค่าธรรมเนียม 110 yugeon โดยไม่มีเงินทอน แต่ถ้าส่ง 0.8 SMW จากอินพุตเดียวกัน จะมีเอาต์พุตสำหรับเงินทอนเพิ่มขึ้น และค่าธรรมเนียมจะเป็น 141 yugeon กระเป๋าจะคืนเงินทอนเมื่อยอดที่เหลือหลังหักค่าธรรมเนียมถึงเกณฑ์ขั้นต่ำที่คำนึงถึงค่าใช้จ่ายในการใช้เงินทอนนั้นในภายหลัง หากเหลือน้อยกว่าเกณฑ์ ยอดที่เหลือจะรวมอยู่ในค่าธรรมเนียมที่แสดงก่อนยืนยัน เมื่อประเมินขนาดอินพุตของกระเป๋าแบบ Native SegWit (P2WPKH) ระบบจะคิดขนาดลายเซ็นรวมชนิดแฮชไม่เกิน 71 ไบต์

0.57.61 · เมื่อเปลี่ยนภาษาขณะเปิดแอปอยู่ ไอคอนบนแถบงานของ Windows จะเปลี่ยนตามด้วย

โดยปกติโหนดจะเปิดการเชื่อมต่อขาออก 10 รายการ ส่วนใหญ่ใช้ส่งต่อทั้งบล็อกและธุรกรรม โหนดอาจใช้การเชื่อมต่อสำรองที่เคยตรวจสอบแล้วเพื่อส่งต่อบล็อก และเปิดการเชื่อมต่อที่ 11 ชั่วคราวเพื่อค้นหาโหนดอื่น การเชื่อมต่อทั้งหมดจำกัดไว้ที่ 125 รายการ ขาเข้าได้สูงสุด 117 รายการ หรือ 115 รายการเมื่อมีขาออก 10 รายการ ตอนนี้แอปบนคอมพิวเตอร์แสดงเฉพาะจำนวนโหนดที่เชื่อมต่อทั้งหมด อุปกรณ์ขุดแต่ละเครื่องสร้างบล็อกของตัวเอง โหนดพีซีจะส่งต่อบล็อกที่เสร็จแล้ว และปฏิเสธคำของานขุดและผลการคำนวณจากโทรศัพท์

เมื่อเริ่มทำงานอีกครั้ง โหนดจะทำงานต่อจากบล็อกล่าสุดที่ตรวจสอบไว้ในเครื่องและตรวจสอบบล็อกใหม่ หากไม่พบบันทึกการตรวจสอบที่เก็บไว้หรือข้อมูลไม่ตรงกัน โหนดจะตรวจสอบประวัติที่เก็บไว้อีกครั้ง

SUMUWW PC 0.57.61 · โหนดตรวจสอบ เก็บ ส่งต่อ และให้ค้นข้อมูลเชน

## รูปแบบลายเซ็น

SDK ซอร์สที่เลือกใช้ได้ประกอบธุรกรรมและตรวจลายเซ็นโดยไม่ใช้กุญแจหรือเครือข่าย ไม่ใช่โปรแกรมลงนามหรือคำสั่งโหนด ข้อจำกัด P2WPKH ใช้กับรูปแบบตัวอย่างเท่านั้น ไม่ใช่โหนด กระเป๋าส่วนตัวเดิมยังใช้งานได้

## RPC และ HTTP API

validateaddress ตรวจเช็กซัมและเครือข่ายที่เลือก decoded_only จาก decoderawtransaction หมายถึงอ่านข้อมูลได้เท่านั้น ไม่ได้รับรองลายเซ็นหรือการยืนยัน OP_RETURN เก็บข้อมูลให้โปรแกรมภายนอก โหนดเพิ่มการสอบถามค่าธรรมเนียม การตรวจสอบก่อนส่ง สถานะการแทนที่ RBF และการอ่านข้อมูลตามลำดับบล็อก ระบบตรวจสอบธุรกรรมใหม่ก่อนลบธุรกรรมที่รออยู่ ลายเซ็นหลายชุดและเอาต์พุตแบบล็อกพัฒนาไว้สำหรับทดสอบการเปิดใช้ในระบบแยก ยังไม่เปิดใช้บนเครือข่ายสาธารณะ

## ค่าธรรมเนียม ธุรกรรมที่ตรวจสอบแล้ว และความเข้ากันได้

ค่าธรรมเนียมคือยอดรวมอินพุตลบด้วยยอดรวมเอาต์พุต การประมาณขนาดจะนับเอาต์พุตเงินทอนเฉพาะเมื่อกระเป๋าสร้างเงินทอนที่ผ่านเกณฑ์จริงเท่านั้น หากยอดที่เหลือต่ำกว่าเกณฑ์ของกระเป๋า ยอดนั้นจะรวมเป็นค่าธรรมเนียม โดยแสดงค่าธรรมเนียมสุดท้ายและยอดหักรวมให้ตรวจสอบ อัตราค่าธรรมเนียมใช้หน่วย yugeon/vB ส่วนขนาดเสมือนคือน้ำหนักธุรกรรมหารด้วยสี่แล้วปัดขึ้น

กระเป๋าเลือกอินพุตและเอาต์พุตเพียงครั้งเดียว แล้วลงนามตามแผนธุรกรรมเดียวกัน เมื่อยืนยันจะส่งธุรกรรมที่ลงนามและเก็บไว้ โดยไม่สร้างธุรกรรมใหม่หรือคำนวณค่าธรรมเนียมซ้ำ หากรายการประมาณการหมดอายุหรืออินพุตถูกใช้ไปแล้ว ต้องตรวจสอบใหม่ การรับเข้าคิวภายในเครื่องยังไม่ใช่การยืนยันในบล็อก

การชำระเงิน P2WPKH ทั่วไปใช้ลายเซ็น low-R และ low-S ที่ยาวไม่เกิน 71 ไบต์รวมไบต์ SIGHASH_ALL นี่คือนโยบายการลงนามและการประมาณขนาดของกระเป๋า ไม่ใช่ข้อจำกัดฉันทามติใหม่สำหรับลายเซ็นที่ถูกต้องอื่น ๆ ลายเซ็นที่สั้นกว่าอาจทำให้ขนาดเสมือนจริงเล็กกว่าค่าประมาณ อัตราที่แนะนำยังคงอ้างอิงคิวภายในโหนด
