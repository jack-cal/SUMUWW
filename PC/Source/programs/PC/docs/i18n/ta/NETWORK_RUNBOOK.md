# SUMUWW · கணு இயக்கம்

முனையம் வழக்கமாக 10 வெளிச்செல்லும் இணைப்புகளைத் திறக்கும். அவற்றில் பெரும்பாலானவை தொகுதிகளையும் பரிவர்த்தனைகளையும் அனுப்பும். ஏற்கெனவே சரிபார்த்த மாற்று இணைப்பைத் தொகுதிகளை அனுப்பப் பயன்படுத்தலாம். பிற முனையங்களைத் தேட 11வது இணைப்பைச் சிறிது நேரம் திறக்கலாம். மொத்த வரம்பு 125. உள்வரும் இணைப்புகள் அதிகபட்சம் 117. வெளிச்செல்லும் இணைப்புகள் 10 இருந்தால் உள்வரும் வரம்பு 115. கணினிச் செயலி இப்போது இணைக்கப்பட்டுள்ள முனைகளின் மொத்த எண்ணிக்கையை மட்டும் காட்டுகிறது. ஒவ்வொரு மைனிங் சாதனமும் தனது பிளாக்குகளைத் தானே உருவாக்குகிறது. கணினி நோடு முடிக்கப்பட்ட பிளாக்குகளைப் பகிர்கிறது. தொலைபேசியிலிருந்து வரும் மைனிங் பணி கோரிக்கைகளையும் அதற்கான விடைகளையும் நிராகரிக்கிறது.

மீண்டும் தொடங்கும்போது, முனையம் தானே சரிபார்த்த கடைசித் தொகுதியிலிருந்து தொடர்ந்து புதிய தொகுதிகளைச் சரிபார்க்கிறது. சேமித்த சரிபார்ப்புப் பதிவு இல்லையெனில் அல்லது அதன் விவரங்கள் பொருந்தாவிட்டால், சேமித்த வரலாற்றை மீண்டும் சரிபார்க்கிறது.


SUMUWW PC 0.57.61 · முனை சங்கிலித் தரவைச் சரிபார்த்து, சேமித்து, பரப்பி, தேடலுக்கு வழங்குகிறது.

## பிணையமும் முகவரிகளும்

பொதுப் பிணையம் `sumuww`; அதன் உள் மாற்றுப் பெயர் `dora`. கீழுள்ள தொடக்கத் தொகுதி hash-ஐச் சரிபார்க்கவும். இயல்பான முகவரிகள் witness v0 P2WPKH மற்றும் சுருக்கப்பட்ட secp256k1 பொதுச் சாவியின் HASH160-ஐப் பயன்படுத்துகின்றன. memo அல்லது tag கட்டாயமில்லை. தவறான பிணையம், செல்லாத checksum ஆகியவற்றை நிராகரிக்கவும். HD பெறுதல்/மீதத்தொகைக் கிளை மற்றும் index-ஐப் பதிவு செய்யவும்; Bitcoin derivation path எனக் கருத வேண்டாம்.

## அங்கீகாரமும் வரம்புகளும்

தனிப்பட்ட Bearer token உடன் எண் loopback `127.0.0.1:18443`-ல் RPC-ஐ வெளிப்படையாக இயக்கவும். பணப்பை திறப்பு அல்லது தொலைக் கையொப்பம் வழங்கப்படவில்லை. உள்ளூர் சேவை அல்லது அங்கீகரித்த tunnel பயன்படுத்தவும்; உலாவியின் Origin/Referer கோரிக்கைகள் நிராகரிக்கப்படும். JSON-RPC: POST `/rpc`, object/array `params`, `id`; அறிவிப்புக்கு HTTP 204. வரம்புகள்: body 8004096 பைட், header 8192, batch 16, ஒரே நேரக் கோரிக்கைகள் 16, நேரம் 10 வினாடி; limit 1–1000, offset 0–1000000. மொத்தம் 28 method, 11 REST வழிகள்.

## பரிவர்த்தனை மற்றும் தொகுதி தேடல்

`getrawtransaction` செயலிலுள்ள சங்கிலி மற்றும் mempool-ஐத் தேடும்; பிரிந்த கிளையில் மட்டுமே உள்ள பரிவர்த்தனையை அல்ல. உள்ளீடுகள் முந்தைய வெளியீடுகளைக் குறிக்கும், ஒரே அனுப்புநர் முகவரியை அல்ல. `getblock`-இன் `verbose` Boolean; சேமித்த செயலற்ற தொகுதிகளில் `active=false`, `confirmations=-1`. தொகுதி hash மூலம் மூலப் பரிவர்த்தனைகள் கிடைக்கும். `findspendingtransaction` செயலில் உறுதியான செலவுகளை மட்டுமே தேடும்; null கிடைப்பதற்கான சான்றல்ல. `include_mempool=true` உடன் `gettxout` பார்க்கவும். மறுசீரமைப்பில் உறுதிகளும் செயல்நிலையும் மாறலாம்.

## சரிபார்ப்பு

தேவையான தொகுப்புகளை நிறுவி மூலத்திலிருந்து python examples/node_contract.py இயக்கவும். பொதுச் சோதனைச் சாவிகளும் தற்காலிக regtest-மும் சமர்ப்பித்தல், மறுப்பு, உறுதிப்படுத்தல், மறுசீரமைப்பு மற்றும் சேமிப்பைச் சோதிக்கின்றன. உண்மையான நிதி, பயனர் சுயவிவரம் அல்லது வன்பொருள் கையொப்பக் கருவி பயன்படுத்தப்படாது.

## கட்டணம், சரிபார்த்த பரிவர்த்தனை மற்றும் இணக்கத்தன்மை

உள்ளீடுகளின் மொத்தத்திலிருந்து வெளியீடுகளின் மொத்தத்தைக் கழித்தால் கட்டணம் கிடைக்கும். பணப்பை தனது வரம்பைப் பூர்த்தி செய்யும் மீதித்தொகையை உண்மையில் உருவாக்கும்போதுதான் அதன் வெளியீடு அளவு மதிப்பீட்டில் சேர்க்கப்படும். வரம்புக்குக் குறைவான மீதித்தொகை கட்டணத்தில் சேர்க்கப்படும்; இறுதிக் கட்டணமும் மொத்தப் பிடித்தமும் சரிபார்ப்பதற்குக் காட்டப்படும். கட்டண விகிதத்தின் அலகு yugeon/vB. பரிவர்த்தனை எடையை நான்கால் வகுத்து மேல்நோக்கி முழு எண்ணாக்கினால் மெய்நிகர் அளவு கிடைக்கும்.

பணப்பை உள்ளீடுகளையும் வெளியீடுகளையும் ஒருமுறை தேர்ந்தெடுத்து அதே பரிவர்த்தனைத் திட்டத்தில் கையொப்பமிடுகிறது. உறுதிசெய்யும்போது சேமித்த கையொப்பமிட்ட பரிவர்த்தனையே அனுப்பப்படும்; அது மீண்டும் அமைக்கப்படாது, கட்டணமும் மறுகணக்கிடப்படாது. மதிப்பீட்டின் காலம் முடிந்தாலோ ஓர் உள்ளீடு ஏற்கெனவே செலவிடப்பட்டாலோ மீண்டும் சரிபார்க்க வேண்டும். உள்ளூர் வரிசையில் ஏற்கப்பட்டதையே தொகுதியில் உறுதியானதாகக் கருதக்கூடாது.

வழக்கமான P2WPKH பணப்பரிமாற்றத்தில், SIGHASH_ALL பைட் உட்பட அதிகபட்சம் 71 பைட்கள் கொண்ட low-R, low-S கையொப்பங்களைப் பணப்பை உருவாக்குகிறது. இது கையொப்பம் மற்றும் அளவு மதிப்பீட்டுக் கொள்கை; பிற செல்லுபடியான கையொப்பங்களுக்கான புதிய ஒருமித்த விதி அல்ல. குறுகிய கையொப்பத்தால் உண்மையான மெய்நிகர் அளவு குறையலாம். பரிந்துரைக்கப்படும் விகிதங்கள் இன்னும் உள்ளூர் வரிசையைச் சார்ந்தவை; Bitcoin போல அளவைக் கணக்கிடுவது அதன் வலையமைப்பின் கட்டண விகிதங்களைப் பயன்படுத்துவதாகாது.

## Windows I2P கூறும் பாதுகாப்புச் சோதனையும்

Windows தொகுப்பில் அதிகாரப்பூர்வ i2pd 3.0.0, புதுப்பித்த ஹாஷ்கள் மற்றும் தொடக்க இணைப்புச் சான்றிதழ்கள் உள்ளன. பதிவுசெய்த சோதனையில் அதிகாரப்பூர்வ I2P இயக்கக் கோப்பையும் அசல் ZIP-ஐயும் Defender இன்னும் கண்டறிகிறது. அதிகாரப்பூர்வ ஹாஷ் பொருந்துவது பாதுகாப்பையோ தவறான கண்டறிதலையோ நிரூபிக்காது. உள்ளூர் கோப்பு விலக்கு பதிவு செய்த கணினியில் மட்டுமே செயல்படும்; பொதுத் தொகுப்பு அதைத் தானாகச் சேர்க்காது. பிற கணினிகள் இதே கோப்புகளைத் தடுக்கலாம்.

செல்லுபடியாகும் பதிப்புத் தகவல் கிடைத்ததும், உறுதிப்படுத்தலை அனுப்ப எதிர்முனைக்குக் கணு நேரம் வழங்குகிறது. வெளியே செல்லும் இரண்டு இணைப்புகளும் ஒரே கணுவை அடைந்தால், அவற்றில் ஒன்று ஒத்திசைவை முடிக்கும் வரை கிடைக்கக்கூடிய பாதை திறந்தே இருக்கும். இணைப்புச் சான்று கிடைப்பதற்கு முன்பே செல்லுபடியாகும் பணிச்சான்றைக் கொண்ட தொகுதியை உள்ளமைந்த சோதனை ஏற்கிறது. அதன் பிறகு மூன்று சாட்சிகளின் கையொப்பங்கள், இணைப்புச் சான்று மற்றொரு முனைக்கு அனுப்பப்படுவது, மறுதொடக்கத்திற்குப் பின்னும் அது சேமிக்கப்பட்டிருப்பது ஆகியவற்றைச் சரிபார்க்கிறது.
