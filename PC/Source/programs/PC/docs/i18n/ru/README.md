# SUMUWW · Документация

SUMUWW PC 0.57.51 · Узел проверяет, хранит, передаёт и предоставляет данные цепочки.

## Формат подписи

Необязательный SDK в исходниках собирает транзакции и проверяет переданные подписи без ключей и сети. Это не программа подписи и не команда узла. Ограничение P2WPKH относится к формату примера, а не к узлу. Прежний личный кошелёк доступен.

## RPC и HTTP API

validateaddress проверяет контрольную сумму и выбранную сеть. decoded_only от decoderawtransaction означает только разбор, а не проверку подписи или подтверждение. Выходы OP_RETURN сохраняют данные для внешних программ. Добавлены запрос комиссии, проверка перед отправкой, состояние замены RBF и чтение данных в порядке блоков. Замена проверяется до удаления ожидающих транзакций. Мультиподпись и блокировка выходов реализованы для изолированных испытаний активации; в публичной сети они пока не активированы.

## Проверка

Установив зависимости, запустите python examples/node_contract.py из исходников. Открытые тестовые ключи и временная regtest проверяют отправку, отказ, подтверждения, реорганизацию и сохранность данных. Реальные средства, профили пользователей и аппаратные устройства подписи не используются.


## Комиссии, проверенная транзакция и совместимость

Комиссия равна сумме входов за вычетом суммы выходов. Выход сдачи учитывается в оценке только тогда, когда кошелёк действительно создаёт сдачу достаточного размера. Остаток ниже порога кошелька добавляется к комиссии; итоговая комиссия и полная сумма списания показываются перед подтверждением. Ставка задаётся в yugeon/vB. Виртуальный размер — это вес транзакции, делённый на четыре с округлением вверх.

Кошелёк один раз выбирает входы и выходы и подписывает этот же план транзакции. При подтверждении отправляется сохранённая подписанная транзакция: она не собирается заново, а комиссия не пересчитывается. Если срок расчёта истёк или вход уже потрачен, нужна новая проверка. Приём в локальную очередь не означает подтверждения в блоке.

Для обычных переводов P2WPKH кошелёк создаёт подписи low-R и low-S длиной не более 71 байта вместе с байтом SIGHASH_ALL. Это политика подписи и оценки размера, а не новое правило консенсуса для остальных действительных подписей. Более короткая подпись может уменьшить фактический виртуальный размер. Рекомендуемые ставки по-прежнему зависят от локальной очереди; сходный с Bitcoin расчёт размера не означает применение ставок сети Bitcoin.

## Компонент I2P для Windows и проверка безопасности

В пакеты Windows включён официальный i2pd 3.0.0 с обновлёнными контрольными суммами и сертификатами начального подключения. В зафиксированной проверке Defender по-прежнему обнаруживает угрозу в официальном исполняемом файле I2P и исходном ZIP. Совпадение с официальным хешем не доказывает безопасность и не подтверждает ложное срабатывание. Локальное исключение действует только на том ПК, где оно задано; публичный пакет его не устанавливает. Другие компьютеры могут заблокировать те же файлы.
