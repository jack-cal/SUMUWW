# SUMUWW · เอกสาร

SUMUWW PC 0.57.51 · โหนดตรวจสอบ เก็บ ส่งต่อ และให้ค้นข้อมูลเชน

## รูปแบบลายเซ็น

SDK ซอร์สที่เลือกใช้ได้ประกอบธุรกรรมและตรวจลายเซ็นโดยไม่ใช้กุญแจหรือเครือข่าย ไม่ใช่โปรแกรมลงนามหรือคำสั่งโหนด ข้อจำกัด P2WPKH ใช้กับรูปแบบตัวอย่างเท่านั้น ไม่ใช่โหนด กระเป๋าส่วนตัวเดิมยังใช้งานได้

## RPC และ HTTP API

validateaddress ตรวจเช็กซัมและเครือข่ายที่เลือก decoded_only จาก decoderawtransaction หมายถึงอ่านข้อมูลได้เท่านั้น ไม่ได้รับรองลายเซ็นหรือการยืนยัน OP_RETURN เก็บข้อมูลให้โปรแกรมภายนอก โหนดเพิ่มการสอบถามค่าธรรมเนียม การตรวจสอบก่อนส่ง สถานะการแทนที่ RBF และการอ่านข้อมูลตามลำดับบล็อก ระบบตรวจสอบธุรกรรมใหม่ก่อนลบธุรกรรมที่รออยู่ ลายเซ็นหลายชุดและเอาต์พุตแบบล็อกพัฒนาไว้สำหรับทดสอบการเปิดใช้ในระบบแยก ยังไม่เปิดใช้บนเครือข่ายสาธารณะ

## ผลการตรวจสอบ

ติดตั้งส่วนประกอบที่จำเป็นแล้วรัน python examples/node_contract.py จากซอร์ส กุญแจทดสอบสาธารณะและ regtest ชั่วคราวตรวจการส่ง การปฏิเสธ การยืนยัน การจัดเชนใหม่ และการเก็บข้อมูล โดยไม่ใช้เงินจริง โปรไฟล์ผู้ใช้ หรืออุปกรณ์ลงนาม

```text
network: sumuww (dora)
genesis: 00000032e243a8c71b449b13c2da733dd329f308a75aa4358f3f22707a28af97
HRP: sumuww
P2P magic: d052470c
1 SMW = 100000000 yugeon
```

## ค่าธรรมเนียม ธุรกรรมที่ตรวจสอบแล้ว และความเข้ากันได้

ค่าธรรมเนียมคือยอดรวมอินพุตลบด้วยยอดรวมเอาต์พุต การประมาณขนาดจะนับเอาต์พุตเงินทอนเฉพาะเมื่อกระเป๋าสร้างเงินทอนที่ผ่านเกณฑ์จริงเท่านั้น หากยอดที่เหลือต่ำกว่าเกณฑ์ของกระเป๋า ยอดนั้นจะรวมเป็นค่าธรรมเนียม โดยแสดงค่าธรรมเนียมสุดท้ายและยอดหักรวมให้ตรวจสอบ อัตราค่าธรรมเนียมใช้หน่วย yugeon/vB ส่วนขนาดเสมือนคือน้ำหนักธุรกรรมหารด้วยสี่แล้วปัดขึ้น

กระเป๋าเลือกอินพุตและเอาต์พุตเพียงครั้งเดียว แล้วลงนามตามแผนธุรกรรมเดียวกัน เมื่อยืนยันจะส่งธุรกรรมที่ลงนามและเก็บไว้ โดยไม่สร้างธุรกรรมใหม่หรือคำนวณค่าธรรมเนียมซ้ำ หากรายการประมาณการหมดอายุหรืออินพุตถูกใช้ไปแล้ว ต้องตรวจสอบใหม่ การรับเข้าคิวภายในเครื่องยังไม่ใช่การยืนยันในบล็อก

การชำระเงิน P2WPKH ทั่วไปใช้ลายเซ็น low-R และ low-S ที่ยาวไม่เกิน 71 ไบต์รวมไบต์ SIGHASH_ALL นี่คือนโยบายการลงนามและการประมาณขนาดของกระเป๋า ไม่ใช่ข้อจำกัดฉันทามติใหม่สำหรับลายเซ็นที่ถูกต้องอื่น ๆ ลายเซ็นที่สั้นกว่าอาจทำให้ขนาดเสมือนจริงเล็กกว่าค่าประมาณ อัตราที่แนะนำยังคงอ้างอิงคิวภายในโหนด การคำนวณขนาดในแนวทางเดียวกับ Bitcoin ไม่ได้หมายความว่าใช้อัตราค่าธรรมเนียมของเครือข่าย Bitcoin

## ส่วนประกอบ I2P ของ Windows และการตรวจสอบความปลอดภัย

แพ็กเกจ Windows มี i2pd 3.0.0 อย่างเป็นทางการ พร้อมแฮชและใบรับรองสำหรับการเชื่อมต่อเริ่มต้นที่อัปเดตแล้ว ในผลตรวจที่บันทึกไว้ Defender ยังตรวจพบไฟล์โปรแกรม I2P และ ZIP ต้นฉบับอย่างเป็นทางการ แฮชที่ตรงกับต้นทางไม่ใช่หลักฐานยืนยันความปลอดภัยหรือยืนยันว่าเป็นการตรวจผิด ข้อยกเว้นไฟล์ในเครื่องมีผลเฉพาะคอมพิวเตอร์ที่ตั้งค่าไว้ แพ็กเกจสาธารณะจะไม่เพิ่มข้อยกเว้นนี้ให้ เครื่องอื่นยังอาจบล็อกไฟล์เดียวกันได้
